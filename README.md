# AI & LLM Ethics Living Literature Tracker

This package turns the 2026 AI/LLM ethics reading guide into a small living-literature monitoring system.

## What it does

On each run it:

1. searches recent scholarly work through **arXiv**, **OpenAlex**, and **Crossref**;
2. watches configured **official AI-policy pages** (NIST, European Commission, OECD.AI, UNESCO, IndiaAI);
3. classifies results into ethics themes such as privacy, bias, persuasion, human–AI relationships, agentic AI, accountability, regulation, and environmental/labor impacts;
4. calculates a transparent 0–100 importance score from topic relevance, source authority, recency, and impact signals;
5. deduplicates primarily by DOI, then canonical URL, then normalized title/year;
6. puts new items into **New This Week** and **Review Queue**;
7. only auto-promotes an item into the stable Curated Library when the source is official and the score crosses the strict configured threshold;
8. rebuilds `AI_LLM_Ethics_Living_Tracker.xlsx`;
9. records every run in **Update Log**.

The separation between automatic discovery and stable curation is intentional: it gives readers current awareness without allowing a keyword search to pollute the high-quality reading list.

## Free/public data sources

- arXiv API: programmatic Atom feed search.
- OpenAlex API: broad scholarly works catalog. Keyless light usage is supported; a free API key is useful for regular use.
- Crossref REST API: public bibliographic metadata and DOI records.
- Official-page watchers: NIST, European Commission, OECD.AI, UNESCO and IndiaAI pages configured in `config/sources.yaml`.

## GitHub setup

1. Create a GitHub repository (private is fine).
2. Upload the contents of this folder to the repository root. Keep `.github/workflows/update_tracker.yml`.
3. In the repository, open **Actions** and enable workflows if GitHub asks.
4. Optional but recommended: create an OpenAlex free API key and save it as the Actions secret `OPENALEX_API_KEY`.
5. Optional: save your email as the Actions secret `CONTACT_EMAIL`; the updater uses it for polite API identification.
6. Run **Update AI Ethics Living Tracker** once manually from the Actions tab.
7. After that, the included workflow runs every **Monday at 08:00 Asia/Kolkata** and commits the refreshed workbook/data back to the repository.

## Local run

```bash
python -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python update_tracker.py
```

To test the scoring/workbook logic without internet:

```bash
python update_tracker.py --offline-demo
```

To rebuild the Excel file from saved data without contacting any source:

```bash
python update_tracker.py --rebuild-only
```

## Where to edit topics and thresholds

Edit `config/sources.yaml`.

Useful settings:

- `lookback_days`: how far back scholarly APIs search.
- `minimum_review_score`: minimum score that can enter the discovery queue.
- `auto_promote_official_score`: strict threshold for official-source automatic promotion.
- `queries`: scholarly discovery searches.
- `themes`: topic-classification keywords.
- `policy_pages`: authoritative institutional landing pages to watch.

## Important quality note

New research—especially preprints—should not be treated as established evidence simply because it scores highly. The workbook labels automated discoveries separately and recommends checking venue/version/status before formal citation.
